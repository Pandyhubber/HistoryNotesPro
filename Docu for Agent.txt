CONTEXT: Python Desktop Note App (SimpleNote Clone)

Architecture:

Language: Python 3.x

UI Framework: customtkinter (Dark Mode, high-DPI scaling).

Database: sqlite3 (Local file: notes_vault.db).

Database Schema:

note_list: (id INTEGER PK, title TEXT) - Stores the identity of each note.

history: (note_id INTEGER, content TEXT, timestamp DATETIME) - Stores every keystroke/snapshot.

Core Logic:

Auto-Save: Triggered on <KeyRelease>. Updates note_list.title (from first line) and inserts a new row into history.

Precision History: >   - Users select a Date (via month buttons + day dropdown).

A time_slider (0-1440 minutes) determines the target time.

Query: SELECT content FROM history WHERE note_id = ? AND timestamp <= ? ORDER BY timestamp DESC LIMIT 1.

State Management: is_viewing_history (bool) prevents the app from auto-saving old historical snapshots as new current states while the user is scrolling the timeline.

Build Info:

Compiled via PyInstaller with --noconsole --onefile.

Target OS: Windows 10/11.
